# lunwenfix 网站设计

首页以清晰的排版入口和可读的文档示例帮助用户理解工具。工作台按选择论文、描述要求、核对格式组织，窄屏使用单列和底部快捷导航。隐私政策与免责声明共用站点导航、页脚和阅读样式。

| 用途 | 色值 |
| --- | --- |
| 站点背景 | `#f6f5ef` |
| 卡片背景 | `#fffefa` |
| 正文 | `#172e2a` |
| 次要文本 | `#51635d` |
| 主操作与品牌色 | `#1e5550` |
| 深色示例背景 | `#123a35` |
| 焦点描边 | `#956219` |
| 表单边界 | `#82958a` |
| 错误提示 | `#a23d35` |

首页大标题和纸张示例使用本机衬线字体。界面正文使用系统无衬线字体，输入框和下拉框保持 16px。主要操作和手机导航的触控高度至少 44px。交互使用可见焦点，支持减少动态效果的系统偏好。

以 [styles.css](../../styles.css) 中的样式和颜色变量为准。
